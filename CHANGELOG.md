# Changelog

All notable changes to VMPro, newest first.

## v4.3
- 🌗 **Dark / Light theme toggle** in the header — your choice is remembered.
- 🎨 **Reworked light mode** so it actually looks good.
- 📶 **Download progress bar** on each app while it downloads.
- 🗓️ **Last updated date** now shown in each app's details dropdown.
- 🧊 **Transparent bottom navigation bar** for a cleaner look.
- Switched analytics to a more scalable backend.

## v4.2
- 📊 **Download progress** — APK downloads now show a live percentage on the button.
- 🔔 **Update notifications** — VMPro tells you when a newer version is available, with a banner under the header and a one-tap Update button.
- ✈️ **Telegram channel** — added the official channel to the About page; opens the Telegram app directly, or your browser if Telegram isn't installed.
- 🌐 **New website** — moved to vmpro.app.
- More reliable analytics reporting and minor stability fixes.

## v4.1
- Fixed the app icon so it shows fully and correctly on all launchers (no themed-icon tint, no clipping).

## v4.0
- First public release: browse and download ReVanced- and Morphe-patched apps, Magisk/KernelSU modules, and MicroG straight from the official GitHub releases — with install, update, and uninstall management, all built from scratch.
